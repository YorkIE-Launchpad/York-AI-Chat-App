Hub AI Governance API — Sample Payloads & ResponsesPrepared for: @Kalrav Parsana

Overview

* Auth: Bearer JWT (same as Hub UI)
* Fiscal year for budgets: May–April (e.g. 2025-05-01 → FY label FY 2025–26)
* Soft budget status: ok | warning | over | unset
* Empty workspace_tags on a grant = allowed in all workspaces
* Catalog is_free = model stays on the org key after the user is over budget
* User allowed-models: root has_budget is false when FY status is over; per-grant has_budget = is_free || user remaining. When over budget, keep free models; paid models need bring-your-own key

Permissions

Permission
	Used for

manage-ai-model-access
	Allowlists, workspaces, access directory, models picker

manage-org-ai-models
	Org model catalog CRUD

manage-ai-budgets
	Create / set budgets

override-ai-budgets
	Change existing budget (requires reason)

Self
	GET own user budget / spend

Authenticated
	POST /api/ai-governance/usage

GET /api/ai-governance/users/:email/allowed-models

Permission: self or manage-ai-model-access
Query (optional):

* scope = explicit | effective (default effective merge)
* workspace = workspace tag filter
* model_id = filter one model

Example: GET /api/ai-governance/users/jane@york.ie/allowed-models?scope=effective&workspace=cursor
Sample response (data):

{
  "email": "jane@york.ie",
  "has_budget": true,
  "grants": [
    {
      "model_id": "gpt-4o",
      "workspace_tags": [],
      "source": "default",
      "is_free": false,
      "has_budget": true
    },
    {
      "model_id": "claude-sonnet-4",
      "workspace_tags": ["cursor", "hub"],
      "source": "user",
      "is_free": true,
      "has_budget": true
    }
  ],
  "model_ids": ["gpt-4o", "claude-sonnet-4"]
}

Root has_budget is false when FY status is over. Per-grant has_budget = is_free || user remaining. When over budget, keep grants with has_budget: true (free models) on the org key and prompt bring-your-own key for paid models.

User AI Budgets — /api/users/:email/ai-budget

GET /api/users/:email/ai-budget

Permission: self or manage-ai-budgets / override-ai-budgets
Query (optional): fy=2025-05-01 (fiscal year start)
Sample response (data):

{
  "id": "b8c9d0e1-f2a3-4567-1234-678901234567",
  "subject_type": "user",
  "subject_id": "jane@york.ie",
  "fiscal_year_start": "2025-05-01",
  "fiscal_year_end": "2026-04-30",
  "fiscal_year_label": "FY 2025–26",
  "amount": 500,
  "currency": "USD",
  "notes": "Standard IC allocation",
  "spent": 128.45,
  "remaining": 371.55,
  "status": "ok"
}

When no budget row exists, id / amount / remaining are null and status is "unset".

PUT /api/users/:email/ai-budget

Create or override user FY budget. If a row already exists, reason is required (override path).
Permission: manage-ai-budgets / override-ai-budgets
Sample request (create):

{
  "amount": 500,
  "currency": "USD",
  "notes": "Standard IC allocation",
  "fiscal_year_start": "2025-05-01"
}

Sample request (override existing):

{
  "amount": 750,
  "currency": "USD",
  "notes": "Raised for Q3 delivery",
  "reason": "Approved by eng lead for project surge",
  "fiscal_year_start": "2025-05-01"
}

Sample response (data): same as GET snapshot (AiBudgetSnapshotDto).
